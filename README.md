# ListCraft Global

Веб-приложение: продавец описывает товар **на русском** (и при желании прикладывает фото) — и получает готовое объявление **на английском** для зарубежных маркетплейсов: заголовок, описание, подтверждённые характеристики, ключевые слова и список того, что стоит уточнить.

Страницы:

- `/` — посадочная страница: что делает сервис, три шага, пример «было → стало» (составлен вручную и так помечен), цены, обработка данных, вопросы;
- `/create` — рабочая часть: форма, генерация, редактирование и копирование результата.

Стек: Next.js (App Router) · TypeScript · Tailwind CSS · Zod · официальный Anthropic SDK. Без БД, авторизации и внешней инфраструктуры.

## Быстрый старт

Нужен Node.js 20.9+.

```bash
npm install
cp .env.example .env.local   # затем впишите ANTHROPIC_API_KEY
npm run dev
```

В Windows PowerShell вместо `cp` используйте `Copy-Item .env.example .env.local`.

Откройте http://localhost:3000.

Без ключа приложение тоже запускается: при попытке генерации покажет инструкцию по настройке и кнопку **демо-примера** (статический пример, явно помеченный как «не ответ ИИ»).

Production-сборка локально:

```bash
npm run build
npm run start
```

Проверки:

```bash
npm run lint        # ESLint
npx tsc --noEmit    # типы (после первого npm run dev или build — Next генерирует типы маршрутов)
npm test            # Vitest: валидация ввода, разбор ответа ИИ, обработка ошибок API, маршрут /api/generate
```

Тесты не обращаются к Anthropic API: вызов модели в них подменяется.

## Переменные окружения

| Переменная | Обязательна | По умолчанию | Описание |
|---|---|---|---|
| `ANTHROPIC_API_KEY` | да (для ИИ) | — | Ключ из [Anthropic Console](https://console.anthropic.com/settings/keys). Используется только на сервере. |
| `ANTHROPIC_MODEL` | нет | `claude-opus-5-5` | Модель Claude. Для экономии можно попробовать `claude-haiku-5-5`. |
| `GENERATION_LIMIT_PER_HOUR` | нет | `10` | Генераций в час с одного IP. |
| `GENERATION_LIMIT_PER_DAY` | нет | `5` | Бесплатная пробная квота: генераций за 24 часа с одного IP. Это же число показано на лендинге. |
| `GENERATION_LIMIT_GLOBAL_PER_DAY` | нет | `300` | Общий суточный лимит экземпляра сервера. |
| `NEXT_PUBLIC_CONTACT_EMAIL` | да (для демо) | — | Почта для ссылок «Сообщить об ошибке», «Оставить отзыв» и «Хочу пакет — оставить заявку» (открывают почтовую программу с готовой темой). Без неё эти ссылки скрыты, а вместо них написано, что контакт пока не указан. |
| `SITE_URL` | нет | — | Публичный адрес сайта (`https://…`) для превью ссылок в мессенджерах и соцсетях. На Vercel можно не указывать. |

После изменения `.env.local` перезапустите `npm run dev`. `NEXT_PUBLIC_CONTACT_EMAIL`, `SITE_URL` и `GENERATION_LIMIT_PER_DAY` (в тексте лендинга) попадают в страницы **при сборке** — в production после их изменения нужна пересборка (`npm run build`).

## Структура

```
app/
  page.tsx                 — посадочная страница
  create/page.tsx          — рабочая часть (генератор)
  layout.tsx, globals.css  — метаданные, оформление, шрифт с кириллицей
  opengraph-image.tsx      — картинка для превью ссылки
  not-found.tsx            — страница 404
  api/generate/route.ts    — POST /api/generate: проверка данных → лимит → Claude
components/
  site-chrome.tsx          — шапка, подвал, ссылки обратной связи
  listing-generator.tsx    — состояние, отправка, ошибки, загрузка, остаток квоты
  product-form.tsx         — поля формы
  photo-upload.tsx         — фото с превью
  listing-result.tsx       — редактируемый результат + копирование
  copy-button.tsx, setup-notice.tsx
lib/
  listing-schema.ts        — Zod-схемы ввода/вывода, лимиты (общие для клиента и сервера)
  demo-listing.ts          — пример для лендинга, «Заполнить примером» и демо (не ИИ)
  site.ts                  — название, экспериментальная цена, контактная почта
  client/prepare-image.ts  — проверка и уменьшение фото в браузере
  server/claude.ts         — вызов Claude, разбор и проверка ответа, обработка ошибок
  server/prompt.ts         — системные инструкции модели
  server/image.ts          — серверная проверка фото по сигнатуре файла
  server/rate-limit.ts     — простые лимиты в памяти (только для разработки)
```

## Как это работает

1. Браузер проверяет форму и уменьшает фото до 1280 px (JPEG, без EXIF) — это экономит токены.
2. Сервер читает не больше ~3,8 МБ тела запроса, повторно проверяет все поля (Zod), формат фото по сигнатуре файла и его размер (≤ 3,75 МБ — столько помещается в лимит API 5 МБ после base64; браузер обычно ужимает фото до сотен КБ).
3. Сервер вызывает Claude со строгой JSON-схемой ответа (тайм-аут 90 с, без автоматических повторов); ответ проверяется Zod и очищается перед отправкой в браузер, а затем ещё раз проверяется в браузере.
   Попытка возвращается в лимит, только если API заведомо не выполнил запрос (ошибка ключа, 429/529, отклонённый запрос); тайм-аут не возвращается — модель могла успеть ответить и списать токены.
4. Пользователь редактирует результат и копирует поля по отдельности или целиком.

Фото и тексты обрабатываются только в памяти и не сохраняются. В логи пишутся только технические данные (модель, число токенов, время ответа, было ли фото, коды ошибок).

## Ранний доступ и цена

- Бесплатно: `GENERATION_LIMIT_PER_DAY` генераций за 24 часа с одного IP (по умолчанию 5), без регистрации. После каждой генерации показывается остаток; при исчерпании — ссылка на раздел «Цены».
- Пакет **25 объявлений за $4.99** — **гипотеза**, а не проверенная цена. **Оплата не подключена**: на сайте прямо написано, что купить пока нельзя и ничего не списывается. Кнопка «Хочу пакет — оставить заявку» открывает письмо на `NEXT_PUBLIC_CONTACT_EMAIL` — число таких писем и есть сигнал спроса. Цена и размер пакета меняются в `lib/site.ts`.
- Обратная связь — только через `mailto:`: сайт ничего не сохраняет и не отправляет сам.
- В production посетитель не видит подсказок по настройке сервера (ключ, модель, баланс Anthropic) — только «Сервис временно недоступен». Подробности ошибки — в журнале сервера.

## Развёртывание

Перед любым вариантом:

1. Создайте отдельный API-ключ в [Anthropic Console](https://console.anthropic.com/settings/keys) и **задайте лимит расходов** (spend limit) для рабочего пространства.
2. Задайте переменные окружения: `ANTHROPIC_API_KEY` и `NEXT_PUBLIC_CONTACT_EMAIL` (без почты на сайте нет ни заявок на пакет, ни обратной связи), при необходимости `SITE_URL`, `ANTHROPIC_MODEL`, лимиты.
   - Для показа покупателям учтите, что квота считается по IP: несколько прогонов с одного ноутбука или из одного офиса быстро её исчерпают. Временно увеличьте `GENERATION_LIMIT_PER_DAY` (и пересоберите) или перезапустите сервер — счётчики в памяти обнулятся.
3. Проверьте `npm run lint`, `npx tsc --noEmit`, `npm test`, `npm run build`.

**Вариант A — один Node.js-сервер (VPS и т.п.)** — лимиты в памяти работают предсказуемо, потому что процесс один:

```bash
npm ci
npm run build
npm run start   # порт 3000; поставьте перед ним nginx/Caddy с HTTPS
```

За прокси лимиты по IP опираются на `x-forwarded-for` — прокси должен перезаписывать этот заголовок, а не дописывать значение клиента.

**Вариант B — Vercel.** Импортируйте репозиторий, добавьте переменные окружения в настройках проекта и разверните. Учтите:
- тариф Hobby — только для некоммерческого использования; для продаж нужен платный план;
- у маршрута `/api/generate` `maxDuration = 120` с — убедитесь, что ваш план допускает такую длительность функций;
- лимиты в памяти действуют отдельно в каждом экземпляре функции и сбрасываются при холодном старте, поэтому бесплатная квота там приблизительная — для публичного запуска нужен общий счётчик (например, Redis).

После развёртывания пройдите сценарий вручную: лендинг → «Создать объявление бесплатно» → «Заполнить примером» → «Создать объявление» → «Копировать всё»; проверьте ссылки обратной связи и превью ссылки в мессенджере.

## Ограничения текущей версии

- **Лимиты генераций хранятся в памяти процесса** — подходят только для локальной разработки и закрытого теста на одном сервере. На serverless-хостинге у каждого экземпляра свои счётчики; IP определяется по `x-forwarded-for`, который можно подделать без доверенного прокси. Перед публичным запуском замените на общее хранилище (например, Upstash Redis) и/или привязку к аккаунту.
- Автотесты покрывают серверную логику; интерфейс проверялся вручную (в том числе полный сценарий с локальной заглушкой вместо Anthropic API), end-to-end тестов в браузере нет.
- Генерация с настоящим ключом в рамках технической проверки не запускалась (ключа не было) — перед запуском проверьте её вручную на нескольких товарах.
- Приложение не проходило аудит безопасности; перед публичным запуском нужны как минимум надёжный rate limit, лимит расходов в Anthropic Console и CAPTCHA/аккаунты от злоупотреблений.
- Vercel Hobby запрещает коммерческое использование — для монетизации нужен платный план или другой хостинг. Тело запроса на Vercel ограничено 4,5 МБ (фото уменьшается в браузере, поэтому обычно это не проблема).
